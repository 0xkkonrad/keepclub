# Naming research

A breadth-first sweep for the app's name across Polish/Slavic, German/Germanic and Egyptian
mythology, filtered for *friendly helper* rather than *monster*. Run 27 July 2026 — one day
**after** the name was already locked to Munin.

So this is not a decision document. It exists for three reasons:

1. **Munin survives a wide sweep.** Odin's raven of memory — who flies out each day and
   returns each night — came out top of a hundred candidates that were generated without
   reference to the existing choice. The name is not a first-idea artefact.
2. **It is a bench.** Deck modes, the mascot's hoard, companion characters, future sub-apps
   and release codenames all need names, and the good ones below are already vetted for
   tone and sayability.
3. **Prior art is thin.** The only established mythology-named app in spaced repetition is
   **Mnemosyne** (Greek memory goddess, 2003–). The lane is open, which also means nothing
   here has been pre-cleared for trademark.

Nothing below has had a domain, App Store or trademark check. The names that *have* — the
public-name and domain idea maze, with prices, collisions and what is still open — are in
[naming-domains.md](naming-domains.md).

## Reserve bench — the ones worth keeping

| Name | Origin | Use it for |
|---|---|---|
| **Hugin** | Odin's other raven, *Thought* | The natural sibling. A second surface, an authoring mode, the desktop app. Munin remembers; Hugin thinks. |
| **Urd / Verdandi / Skuld** | The Norns — what has been, what is becoming, what shall be | Ready-made names for review states or the three horizons in the forecast. Germanic and structurally exact for spaced repetition. |
| **Skarbnik** | Silesian mine spirit, the treasure keeper | The hoard. Munin's collection of shiny things already exists in the visual language — this is its warden. |
| **Wepwawet** | Egyptian jackal, *"opener of the ways"* | A learning path or curriculum feature. |
| **Khepri** | Egyptian scarab of the morning sun; daily becoming | The daily-session concept, or a morning-review mode. |
| **Fylgja** | Germanic follower-spirit bound to one person for life | The most literal "companion" word found. Hard to spell. |
| **Schrat** | German cognate of Polish *skrzat* — one word, both cultures | A localised mascot name if PL/DE ever matters. |
| **Holle** | Frau Holle rewards the diligent, shames the idle | Streaks. Do not make her mean; the app's tone is not punitive. |
